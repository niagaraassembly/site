# Flags

PNG renderings (120px wide) of Wikimedia Commons SVGs, fetched 2026-10-10.
PNG rather than SVG so no image can carry script.

| File | Source | License |
|---|---|---|

| ny.png | https://commons.wikimedia.org/wiki/File:Flag_of_New_York.svg | Public domain |

A MAG issue page shows its flags in the frame's top-right corner
(`.mag-flags`, assets/css/mag.css). Each MAG lists its own in its markup.
