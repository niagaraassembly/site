# Copy archive

Text drafted by agents (and the alternatives that were not chosen) is saved
here before or as it goes live, so wording can be traced, reused or
reverted without digging through git history.

## Convention

- One folder per page or area, mirroring the site path where practical:
  `copy/frontpage/` for `/`, `copy/services/na/` for `/services/na/...`,
  `copy/places/` for `/places/...`.
- One Markdown file per piece of copy. Start with the date it was written,
  the brief it answered, and where it is live (file and element id/class).
- When several drafts are offered, keep all of them in the one file and mark
  the chosen draft and the date it was chosen.
- The page's HTML stays the authority for what is live. If the two differ,
  the HTML is right and the archive file gets a dated note.

The site's other working mechanics are indexed in
[`docs/MECHANICS.md`](../docs/MECHANICS.md).
