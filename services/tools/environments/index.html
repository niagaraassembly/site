Environments

Environments is our work on industry-specific bench software: purpose-built, open source workbenches for the people who design, test, program and run physical things. We build them on Eclipse Theia, an open source platform for making exactly this kind of tool.

Early stage. We are pioneering modules and complete environments and testing them in the Greater Niagara region. This is work in progress, not a finished product.

What Theia is

An IDE (integrated development environment) is the workbench where software gets written, run and debugged, all in one place. Most people know the finished ones. Eclipse Theia is different: it is the platform you build one from. It is open source, run by the Eclipse Foundation, and lets a team make a tailored tool that runs in a browser or as a desktop app from a single source. It began in 2016, started by Ericsson and TypeFox, and is still shipping regular releases, with an AI-native Theia IDE alongside the platform.

The point is that you do not have to start from nothing, and you do not have to take someone else’s tool as it comes. You assemble the environment your trade needs.

The terms, in plain English

TermWhat it means
PlatformThe set of parts an IDE is built from. Theia is a platform, so you build your own IDE from it.
ExtensionAn add-on that gives an environment a new ability. Theia hosts VS Code extensions and has its own, deeper Theia extensions.
Language server (LSP)A standard way to add language smarts, such as completion and error checking, to any editor.
Debug adapter (DAP)A standard way to connect a debugger to an editor.
Open VSXAn open registry of extensions that Theia can draw on.
White-labelA product built on Theia that carries its own name and design, not Theia’s.
GLSPAn Eclipse technology for diagram-style editors, such as ladder logic.

Theia and VS Code

Theia reuses good parts of VS Code, including its editor, extension model and language and debug standards, but it is not a fork of it. Per the Eclipse community (who back Theia, so read it with that in mind):

VS CodeTheia
Built asAn extensible code editor.A platform for building custom tools and IDEs.
RunsAs a developer IDE.On desktop and in the cloud from one technology stack.
ExtendsThrough the VS Code extension API.Through VS Code extensions and Theia extensions, with deep access to internals.
OpennessThe downloadable product is under a Microsoft licence and includes some proprietary parts.Open source components, vendor-neutral governance under the Eclipse Foundation.

Why it suits industry

  • Shaped to the trade. An environment can show only what a job needs, in the terms the people doing it use.
  • Runs in a browser. One source can serve shared bench machines and Members’ own laptops, with nothing special to install.
  • Graphical when it should be. Ladder logic and process diagrams are pictures, and GLSP-style editors let a tool show them that way.
  • Builds on a large ecosystem. It hosts VS Code extensions, so we reuse rather than reinvent.
  • Open and vendor-neutral. No single company decides its future, which fits an open, local approach to industrial software. See also Gage.
